UZDoom에서 자주 사용하는 콘솔 명령어와 아이템 코드를 정리해두었다. 필요해서 쓰려고 하니, 잘 정리해둔 곳이 없더라고...

# 콘솔 명령어

## 일반 플레이 중 사용할 만한 명령어

| 명령어                      | 설명                                                                                |
| :-------------------------- | :---------------------------------------------------------------------------------- |
| `anubis`                    | 적들이 플레이어를 두려워해 도망치거나 공격을 주저하게 하는 효과를 켜거나 끈다.      |
| `buddha` / `buddha2`        | 체력이 1 아래로 떨어지지 않게 한다. `buddha2`는 텔레프래그 같은 즉사 효과도 막는다. |
| `god` / `god2`              | 일반적인 피해를 받지 않게 한다. `god2`는 텔레프래그 같은 즉사 효과도 막는다.        |
| `noclip` / `noclip2`        | 벽과 물체를 통과한다. `noclip2`는 중력도 끄고 3D 바닥도 통과한다.                   |
| `drop <아이템 코드> [수량]` | 가지고 있는 아이템을 바닥에 떨어뜨린다.                                             |
| `fly`                       | 비행 모드를 켜거나 끈다.                                                            |
| `notarget`                  | 먼저 공격하지 않는 한 적이 플레이어를 표적으로 삼지 않게 한다.                      |
| `resurrect`                 | 죽은 플레이어를 부활시킨다.                                                         |
| `take <아이템 코드> [수량]` | 가지고 있는 아이템을 제거한다.                                                      |
{style="width: auto"}

## 뭔가 꼬였을 때 사용할 만한 명령어

| 명령어                | 설명                                                                                                               |
| :-------------------- | :----------------------------------------------------------------------------------------------------------------- |
| `warp <x> <y> [z]`    | 현재 맵의 지정한 좌표로 이동한다. `z`를 생략하면 바닥으로 이동한다.                                                |
| `kill [클래스]`       | 인자를 생략하면 플레이어가 죽는다. `monsters`는 모든 몬스터를, 특정 클래스 이름은 해당 클래스의 개체들을 처치한다. |
| `changemap <맵 이름>` | 현재 게임을 이어 지정한 맵으로 이동한다. 맵 이름 대신 `*`를 쓰면 현재 맵을 다시 시작한다.                          |
| `endgame`             | 현재 게임을 종료하고 콘솔 화면으로 돌아간다.                                                                       |
| `finishgame`          | 게임 종료 동작을 실행한다. 마지막 맵을 끝내도 종료되지 않는 모드에서 사용할 수 있다.                               |
| `map <맵 이름>`       | 지정한 맵에서 새 게임을 시작한다. 체력과 인벤토리가 초기화된다.                                                    |
| `nextmap`             | 다음 맵에서 새 게임을 시작한다. 체력과 인벤토리가 초기화된다.                                                      |
| `nextsecret`          | 비밀 출구의 목적지 맵에서 새 게임을 시작한다. 체력과 인벤토리가 초기화된다.                                        |
{style="width: auto"}

# 아이템 목록

간혹 `give` 명령어로 아이템을 소환할 때가 있는데, 아이템 코드를 제대로 정리한 글을 찾을 수 없어 직접 확인 후 정리해두었다.

둠 이외의 아이템 코드는 `dumpclasses inventory` 명령어로 현재 등록된 모든 아이템 코드를 출력하여 확인할 수 있다.

`give` 명령어는 `give <아이템 코드> [수량]`으로 사용하면 된다.

## 헬스 및 아머 아이템

둠에는 '헬스(체력, Health)' 외에도 '아머(방어구, Armor)'라는 시스템이 있다.
기본 혹은 초록색 아머('아머')를 획득할 경우에는 받은 대미지의 1/3을 아머가 대신 받아주고, 파란색 아머('메가 아머')를 획득한 경우에는 받은 대미지의 1/2를 아머가 대신 받아준다.
아머를 새로 획득하면 아머 수치와 흡수율이 함께 바뀐다. 다만 현재 아머가 100 이상이면 초록색 아머는 획득되지 않는다. 파란색 아머가 100 미만으로 줄어든 뒤 초록색 아머를 획득하면 아머가 100이 되고 흡수율은 1/3로 바뀐다.

| 아이템      | 아이템 코드   | 설명                                                 |
| :---------- | :------------ | :--------------------------------------------------- |
| 헬스 보너스 | `healthbonus` | 물약이 담긴 파란색 플라스크, 헬스 +1 (200까지)       |
| 스팀팩      | `stimpack`    | 작은 구급상자, 헬스 +10 (100까지)                    |
| 메디킷      | `medikit`     | 큰 구급상자, 헬스 +25 (100까지)                      |
| 아머 보너스 | `armorbonus`  | 금속 헬멧, 아머 +1 (200까지)                         |
| 아머        | `greenarmor`  | 초록색 갑옷, 아머 100까지 증가 + 흡수율 1/3으로 설정 |
| 메가 아머   | `bluearmor`   | 파란색 갑옷, 아머 200까지 증가 + 흡수율 1/2으로 설정 |
{style="width: auto"}

## 기타 아이템

| 아이템        | 아이템 코드  | 설명                                                                                                       |
| :------------ | :----------- | :--------------------------------------------------------------------------------------------------------- |
| 방사능 차폐복 | `radsuit`    | 대미지 플로어로 인한 피해를 60초간 대부분 차단[^1]                                                         |
| 부분 투명화   | `blursphere` | 적의 원거리 공격의 정확도 하락                                                                             |
| 야간투시경    | `infrared`   | 화면을 120초간 밝게 유지                                                                                   |
| 컴퓨터 지도   | `allmap`     | 현재 맵의 전체 지형을 자동 지도에 표시                                                                     |
| 백팩          | `backpack`   | 탄약 최대 소지량 2배 증가 (최초 1회만 적용)<br>획득할 때마다 실탄 10발, 산탄 4발, 로켓 1발, 전지 20발 획득 |
{style="width: auto"}

[^1]: 높은 피해를 주는 일부 바닥에서는 방사능 차폐복을 입고 있어도 확률적으로 피해를 입을 수 있다.

## 특수한 아이템 코드

`give`에서는 개별 아이템 코드 대신 다음 단어도 사용할 수 있다.

| 코드         | 효과                                                         |
| :----------- | :----------------------------------------------------------- |
| `all`        | 무기, 탄약, 아머, 열쇠 등을 얻는다.                          |
| `everything` | `all`에서 제외된 일부 대체 아이템과 치트 제외 무기도 얻는다. |
| `health`     | 체력을 최대로 회복한다.                                      |
| `weapons`    | 무기 슬롯에 등록된 무기들을 얻는다.                          |
| `ammo`       | 탄약을 최대치까지 채운다.                                    |
| `armor`      | 아머를 최대치까지 채운다.                                    |
| `keys`       | 잠금장치에 지정된 열쇠를 모두 얻는다.                        |
{style="width: auto"}
